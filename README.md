# JetSetGo

**JetSetGo** is a smart travel planning web application designed to make trip organization easy, fun, and collaborative. From planning itineraries to tracking expenses, JetSetGo helps users manage every aspect of their journey in one place.

---

## About the Project

JetSetGo is developed as part of a **Software Design & Architecture (SDA)** project.
It focuses on solving real-world travel planning challenges by combining productivity tools with social and gamified features.

---

## Features

* **Travel Checklists**
  Organize packing lists and important pre-trip tasks

* **Trip Planning**
  Plan destinations, travel dates, and activities

* **Budget Management**
  Track expenses and manage trip budgets efficiently

* **Itinerary Planning**
  Create structured daily travel schedules

* **Expense Sharing**
  Split trip costs easily with friends

* **Gamification**
  Earn badges and XP by completing tasks

* **Posts & Reviews**
  Share travel experiences and feedback

*  **Popular Destinations**
  Explore trending locations and hidden gems

## Installation & Setup

```bash
# Clone the repository
git clone https://github.com/your-username/jetsetgo.git

# Navigate into the project
cd jetsetgo

# Install dependencies
pip install -r requirements.txt

# Run the application
python app.py
```
